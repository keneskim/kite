# kite 入门教程

这是一门小语言的教程。**从第一课开始照着敲**，每课都能跑。

```
python3 kite.py 程序.kite --run     # 生成 C、编译、运行，一条命令
```

学完你能写：命令行小工具、竞赛类算法题、能读键盘的互动小游戏。

---

# 第 1 课 让程序说话

新建 `hello.kite`：

```
p "你好，kite！"
```

```
$ python3 kite.py hello.kite --run
你好，kite！
```

`p` 是打印。引号里的都是文本，原样输出，末尾自动换行。

**练习**：打印三行，每行一句不同的话。

---

# 第 2 课 记住东西

变量就是给一个值起名字：

```
name = "小明"
age = 18
p "{name} 今年 {age} 岁"
```

```
小明 今年 18 岁
```

- 第一次写 `名字 = 值` 就创建了它，不用声明
- `{...}` 里可以放任何表达式，会被算出来再塞进文本
- 数字不用引号，文本要引号

**练习**：造三个变量（名字、年龄、城市），用一句话打印出来。

# 第 3 课 做选择

```
n = 7
if n % 2 == 0
    p "偶数"
else
    p "奇数"
```

```
奇数
```

**缩进就是"属于这个 if"**。缩进错了含义就变了，所以每一层都要对齐。

多路选择用 `elif`：

```
score = 85
if score >= 90
    p "优秀"
elif score >= 60
    p "及格"
else
    p "不及格"
```

比较运算：`==` `!=` `<` `>` `<=` `>=`
逻辑运算：`&&`（并且）、`||`（或者）、`!`（不）

> 条件只接受数字。真假就是 `1` 和 `0`。条件里"非 0 为真"，所以 `p 3 > 2` 打印的是 `1`。

**练习**：判断一个数能不能被 3 整除。

# 第 4 课 重复

只有一种循环：`rp`。**后面跟什么，就按什么重复。**

### 重复固定次数

```
rp 3
    p "第 {count} 次"
```

```
第 1 次
第 2 次
第 3 次
```

每一轮的值自动叫 `count`，不用自己维护计数器。

### 数一个范围

```
total = 0
rp 1..5
    total = total + count
p "和 =", total
```

```
和 = 15
```

`1..5` 含 1 也含 5。起点大于终点时倒着数。次数和范围端点在进入循环时各算一次。

### 给每一轮的值起个名字

默认叫 `count`。想换名字就写 `rp 名字 in 来源`：

```
rp i in 1..3
    p i * i
```

```
1
4
9
```

**嵌套循环时必须起名字**，否则内层会盖掉外层：

```
rp i in 1..2
    rp j in 1..2
        p i, j
```

```
1 1
1 2
2 1
2 2
```

### 一直做到某件事成立

```
n = 3
rp ut n <= 0
    p n
    n = n - 1
```

```
3
2
1
```

`rp ut` 读作"重复，直到……"。**循环体里必须有人改变量**，否则永远不停——编译器会提醒你：

```
提醒：第 2 行的 rp ut 循环里没有任何变量被改动，可能会一直重复
```

### 提前退出

- `break` 立刻跳出整个循环
- `continue` 跳过这一轮剩下的，直接下一轮

**练习**：算 1 到 100 里所有偶数之和。

# 第 5 课 写函数

把一段逻辑起个名字，反复用：

```
fn sq(x)
    ret x * x

p sq(7)
p sq(9)
```

```
49
81
```

**不用写类型**——编译器看你怎么调用它，自己推。

```
fn greet(who)
    ret "你好，" + who

p greet("小明")
p greet("小红")
```

```
你好，小明
你好，小红
```

`ret` 把值交回给调用者。返回值的函数需要保证每条路径都执行 `ret 值`。没有 `ret` 的函数只能当语句用：

```
fn show(a)
    p "值是 {a}"

show(3)
```

如果推不出来（比如函数从没被调用过），编译器会直接说，你也可以手写标注兜底：

```
fn double(x: number) -> number
    ret x * 2
```

**练习**：写一个函数，判断一个年份是不是闰年。

# 第 6 课 数组

```
xs = [3, 1, 2]
p xs                # [3, 1, 2]
p xs.len            # 3
p xs[1]             # 3   ← 从 1 开始数
p xs[-1]            # 2   ← 负数从后往前
```

> **下标从 1 开始**：`xs[1]` 是第一个，`xs[0]` 会报错。

### 遍历

```
rp xs
    p count * 10
```

```
30
10
20
```

这里的 `count` 是数组元素。需要下标时，写 `rp i in 1..xs.len`，并先判断数组非空。

### 改一个

```
xs[2] = 100
p xs                # [3, 100, 2]
```

### 追加

```
xs = [1, 2, 3]
xs.push(4)
xs.push(5)
p xs                # [1, 2, 3, 4, 5]
p xs.len            # 5
```

数组能变长，不用先算好大小。要复制一维数组，用 `ys = xs[1..-1]`。数组变量不能直接互相赋值。函数可以修改数组参数的元素，不能对参数 `push`。

### 切片

```
nums = [10, 20, 30, 40, 50]
p nums[2..4]        # [20, 30, 40]
p nums[2..-1]       # [20, 30, 40, 50]

s = "abcdef"
p s[1..3]           # abc
p s[3..-1]          # cdef
```

`a..b` 表示"从第 a 个到第 b 个"，**两头都包含**；`-1` 表示最后一个。

### 常用函数

```
xs = [3, 1, 2]
p xs.sum            # 6
p xs.max            # 3
p xs.min            # 1
p xs.avg            # 2

sort(xs)
p xs                # [1, 2, 3]

p xs.has(2)         # 1（有）
p xs.times(1)       # 1（出现几次）
```

- `sort` 是**原地排序**，会改掉原来的顺序

### 文本和数组互转

```
words = split("苹果,香蕉,梨")
p words              # ["苹果", "香蕉", "梨"]
p words.join("/")    # 苹果/香蕉/梨
```

> 越界会直接报错：
> `出错了：第 2 行越界（下标 10，长度 3，从 1 开始数）`

**练习**：造一个数组，把每个元素乘以 2 后 `push` 进一个新数组，再打印。

# 第 7 课 二维表

```
m = [[1, 2], [3, 4]]
p m                  # [[1, 2], [3, 4]]
p m.len              # 2（行数）
p m[1].len           # 2（列数）
p m[2][1]            # 3

m[1][2] = 9
p m                  # [[1, 9], [3, 4]]
```

行和列都从 1 开始数。

### 造大表

字面量写不了 100 行，用 `mat`：

```
t = mat(3, 3, 0)     # 3 行 3 列，全填 0
t[2][2] = 7
p t                  # [[0, 0, 0], [0, 7, 0], [0, 0, 0]]
```

填充值也可以是文本：`mat(2, 2, "-")`。

### 按行遍历

```
m = [[1, 2], [3, 4]]
rp row in m
    p row
```

```
[1, 2]
[3, 4]
```

**练习**：用二维表打印一个 5×5 的乘法表。

# 第 8 课 处理文字

```
s = "  Hello  "
p s.len          # 9
p s.trim         # Hello
p s.trim.up      # HELLO
p s.trim.low     # hello
```

### 转来转去

```
p num("42") + 1      # 43（文本转数字）
p txt(7) + "!"       # 7!（数字转文本）
```

`len`、文本切片、`find` 和 `sub` 按 Unicode 码点计数。`find` 和 `sub` 从 0 开始，切片从 1 开始且包含两端。`num` 接受十进制数字和科学记数法，空白文本转为 0，非法文本报运行错误。数字输出保留最多 15 位有效数字。

### 插值

```
a = 3
b = 4
p "{a} 加 {b} 等于 {a + b}"     # 3 加 4 等于 7
```

转义：`\n` 换行、`\t` 制表符、`\"` 引号、`\{` 真正的花括号。

**练习**：把 `"  kite  language  "` 变成 `Kite Language`。

# 第 9 课 和用户互动

```
name = ask("你叫什么？")
p "你好，{name}"
p "名字长度：", name.len
```

`ask` 显示提示语，读一行，**返回文本**。要当数字用就套 `num`：

```
n = ask("输入一个数：").num
p "它的两倍是", n * 2
```

### 随机数

```
seed(7)                 # 固定种子：同样种子出同样结果
p rand(100)             # 0 到 99
p rand(100) + 1         # 1 到 100
```

不写 `seed` 就每次都不一样；写了就固定，方便调试。

### 完整例子：猜数字

```
seed(7)
target = rand(100) + 1
tries = 0
won = 0

rp ut tries >= 10
    g = ask("猜一个 1-100 的数：").num
    tries = tries + 1
    if g < target
        p "小了"
    elif g > target
        p "大了"
    else
        p "猜对了！用了 {tries} 次"
        won = 1
        break

if won == 0
    p "次数用完了，答案是 {target}"
```

**练习**：把次数从 10 改成 5，再改成"无限次"。

# 第 10 课 存和读文件

```
write("/tmp/note.txt", "第一行\n第二行")
p read("/tmp/note.txt")
```

`write` 会覆盖原文件；`read` 读不到时返回空文本。

**练习**：把一段文本写进文件，再读回来统计有多少个字符。

# 第 11 课 做成 Windows 程序

```
python3 kite.py 程序.kite --exe
```

```
已生成 程序.c
已生成 程序.exe（Windows 程序）
```

生成的 `.exe` 约 250KB，**静态链接**，拷到 Windows 上双击就能跑，不用装任何运行库。

**但要说清楚：这是控制台程序。** 双击会弹出一个黑框，里面是文字。

```
┌────────────────────────┐
│ 你好，kite！            │
└────────────────────────┘
```

不是带按钮、窗口的那种图形软件——kite 现在还没有界面 API。想要图形界面，得靠网页或真正的 GUI 框架。

**练习**：写一个"单位换算器"（比如公里转英里），做成 exe。

# 第 12 课 做个网页界面

控制台程序是黑框加文字。想要输入框和按钮，就给它一个**网页界面**：

```
fn page()
    km = form('km').num
    ret "<!doctype html><meta charset=utf-8>
<h1>公里换算</h1>
<form>
  公里：<input name=km value='{html(form('km'))}'>
  <button>换算</button>
</form>
<h2>{km} 公里 = {km * 0.6214} 英里</h2>"

serve(8099, page)
```

```
$ python3 kite.py web.kite --run
界面已启动：http://localhost:8099
```

浏览器打开这个地址，就是你的界面。

**三个新东西：**

| 写法 | 意思 |
|---|---|
| `serve(端口, 函数名)` | 起一个本地服务，一直不退出 |
| 函数返回文本 | 每次有人访问/提交，就调用它，返回的文本就是页面 |
| `form('名字')` | 取表单里提交的值（没提交就是空文本） |
| `html(文本)` | 转义文本，便于放进 HTML 正文或带引号的属性 |

**文本可以跨行写**，不用 `\n` 拼。上例里那段 HTML 就是一个双引号字符串，跨了好几行。

**注意一个坑**：CSS 里的 `{}` 会被当成插值。要么写成 `\{` `\}`，要么像上面那样用内联 `style='...'` 避开。

`serve` 仅监听当前设备的 IPv4 回环地址 `127.0.0.1`。适用于本地演示。

**做成 exe**：`--exe` 编译出来的程序双击后也会起服务，浏览器打开同一个地址。用的就是 Windows 的 socket 库，编译时已自动链接。

**练习**：做一个"待办清单"页面，输入框加事项，下面列出来。

# 附录 A 速查表

## 关键字（13 个）

```
p  if  elif  else  rp  ut  in  fn  ret  break  continue  true  false
```

## 值与类型

| 类型 | 例子 |
|---|---|
| 数字 | `42`、`3.14`、`true`(=1)、`false`(=0) |
| 文本 | `"你好"` |
| 数组、二维表 | `[1, 2, 3]`、`mat(2, 3, 0)` |
| 记录 | `Point(2, 3)`（需要先声明 [记录类型](modules.md#定义和使用记录)） |

变量第一次赋值时定类型，之后不能混用。

## 运算符（优先级从低到高）

```
||  &&  !  == != < > <= >=  ..  + -  * / %  一元 -
```

- `/` 是真除法：`7 / 2` 得 `3.5`
- `%` 取余
- `+` 遇到文本就拼接：`"共 " + 3` 得 `"共 3"`

## 点号写法

`a.f(b)` 就是 `f(a, b)`，把第一个参数挪到前面，从左往右读：

```
s.trim.up       就是  up(trim(s))
xs.join("-")    就是  join(xs, "-")
```

对记录，`point.x` 直接读取字段 `x`。

## 内置函数

| 函数 | 作用 |
|---|---|
| `len(x)` | 长度（文本 / 数组 / 表格行数） |
| `txt(x)` | 转成文本 |
| `num(s)` | 转成数字 |
| `up(s)` / `low(s)` | 全大写 / 全小写 |
| `trim(s)` | 去掉两端空白 |
| `read(路径)` / `write(路径, 内容)` | 读 / 写文件 |
| `sum(xs)` / `avg(xs)` | 求和 / 平均 |
| `max(xs)` / `min(xs)` | 最大 / 最小 |
| `sort(xs)` | 原地排序 |
| `join(xs, 分隔符)` | 拼成一串（分隔符默认逗号） |
| `split(文本, 分隔符)` | 拆成数组（默认逗号） |
| `times(xs, 值)` | 值出现了几次 |
| `has(xs, 值)` | 有没有（1 或 0） |
| `ask(提示语)` | 读一行键盘输入 |
| `rand(n)` | 0 到 n-1 的随机数 |
| `seed(n)` | 固定随机种子 |
| `mat(行, 列, 填充)` | 造一张二维表 |
| `xs.push(值)` | 往数组末尾加一个（数组会变长） |
| `abs(x)` / `floor(x)` / `round(x)` | 绝对值 / 向下取整 / 四舍五入 |
| `sqrt(x)` / `pow(a, b)` | 开方 / 幂 |
| `rep(s, n)` | 文本重复 n 次 |
| `find(s, t)` | t 在 s 里的位置，找不到 -1 |
| `sub(s, 起点, 长度)` | 截取一段 |
| `repl(s, 旧, 新)` | 全部替换 |
| `now()` / `date()` / `ts()` | 当前时间 / 日期 / 时间戳 |
| `exist(路径)` / `del(路径)` | 文件在不在 / 删文件 |
| `hex(n)` / `bin(n)` | 转十六进制 / 二进制文本 |
| `serve(端口, 函数名)` | 起一个本地网页界面 |
| `html(文本)` | 转义 HTML 文本（C 后端） |
| `form(名字)` | 取表单里提交的值 |

# 附录 C 边界

1. 没有指针和枚举；可以用[记录](modules.md#定义和使用记录)组织相关数据
2. 数字和文本数组最多两维，每行等长，不能整行赋值；[记录数组](modules.md#一维记录数组)支持一维
3. 函数不能返回数组（返回后内存会失效）
4. 没有字典 / `switch`
5. C 后端不会回收运行中分配的数组和文本
6. 数字是双精度浮点，整数超过 2^53 会不准
7. 顶层变量无法在函数里读取；可用[模块](modules.md#导入模块)共享函数和记录声明
8. 递归深度受目标运行时和栈空间限制
9. `--exe` 生成的是控制台程序；想要界面用 `serve` 起网页，没有原生窗口
10. 网页界面是单页的，不支持多页路由和 JS 回调

# 附录 D 和 C 的对应

| kite | 生成的 C |
|---|---|
| `x = 1` | `double x = 1.0;` |
| `p a, b` | `printf("%g %s\n", a, b);` |
| `rp 5` | `for (double count = 1; count <= 5; count += 1)` |
| `rp xs` | `for (int __i = 0; __i < xs.n; __i++)` |
| `rp ut 条件` | `while (!(条件))` |
| `xs[1]` | `rt_get_num(xs, 1, 行号)`（从 1 数，带越界检查） |
| `m[1][1]` | 先取行再取元素，两层都查越界 |
| `"a{x}b"` | `rt_cat(rt_cat("a", x 转文本), "b")` |
| `fn f(a)` | `double f(double a)` |

生成出来的 C 里，部分语句旁有 `/* kite:行号 */`，gcc 报错时对着看。
