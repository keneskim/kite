# 从零写一个

每个文件都能单独跑：

```
python3 kite.py tutorial/06-final.kite --run
```

| 文件 | 学到什么 |
|---|---|
| `01-print.kite` | 让程序说一句话 |
| `02-state.kite` | 用变量记住状态（血量） |
| `03-one-hit.kite` | 改变状态：扣血 |
| `04-loop.kite` | 重复到结束（rp ut） |
| `05-turns.kite` | 轮流行动（if + 回合数） |
| `06-final.kite` | 把重复的算式抽成函数 |
| `07-mistake.kite` | 故意写错，看编译器怎么提醒你 |

建议顺序：先照着敲一遍，每敲完一个就跑一次。
